# 小优价值说明一页纸 V0

## 一句话

小优是托管机构的数字员工：它持续理解机构事实、老板目标和一线反馈，把散落的信息整理成老板能用的运营判断材料，并在权限边界内协助推进。

## 老板最容易感知的价值

- 少漏事：把老板说过的目标、老师反馈、待确认事项和风险点持续沉淀。
- 少追问：先查已有事实，再判断缺什么，能自己说明为什么需要确认。
- 少跑偏：有机构手册、业务常识和边界，回复不像通用客服。
- 少风险：写入、外发、权限、幂等、审计和写后反查由系统兜底。

## 第一阶段适合交付的能力

- 老板助手：回答机构状态、目标推进、风险和待确认事项。
- 店长助手：整理现场问题、老师反馈、缺口和建议。
- 老师助手：轻量记录、学生状态补充、风险上报材料。
- 每日工作汇报：早间安排、晚间日报、等待事项和证据来源。

## 第一阶段不承诺的能力

- 不承诺全自动招生、全自动续费或全自动管理。
- 不承诺替老板做最终经营决策。
- 不承诺自动联系家长或老师。
- 不承诺一次上线就替代现有管理制度。

## 试点成功标准

- 老板觉得小优“知道我这家机构的事”。
- 店长觉得小优能帮忙整理现场问题，而不是增加负担。
- 老师觉得记录和反馈更轻，不是被系统考核。
- 一周内形成可复盘的价值证据：少漏事项、风险发现、目标推进、资料补齐。
