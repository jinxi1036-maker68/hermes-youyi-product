# 试点报价与交付边界草案 V0

本文是销售沟通草案，不是正式合同。

## 推荐试点形态

- 周期：7-14 天。
- 范围：一家机构，一个独立租户。
- 账号：老板账号必开，店长账号建议开，老师账号小范围灰度。
- 数据：只导入试点需要的最小资料，不导入历史聊天和敏感财务。
- 外发：家长自动发送默认关闭；老师/店长主动外发默认候选或需授权。

## 交付内容

- 机构事实手册。
- 角色和权限配置。
- 老板目标与当前关注事项配置。
- 小优工作日报和待确认事项。
- 首次启动验收报告。
- 试点复盘报告。

## 不包含内容

- 不迁移客户全部历史系统。
- 不承诺自动替代店长管理。
- 不做复杂 SaaS 后台定制。
- 不接入真实支付、薪资或绩效自动结算。
- 不承诺未经审核的家长批量触达。

## 报价表达建议

第一轮报价建议按“试点服务费 + 后续月服务费”表达，不按普通软件账号数表达。

- 试点服务费覆盖：初始化、资料整理、验收、试点陪跑和复盘。
- 月服务费覆盖：小优运行、基础维护、版本升级、日常巡检。
- 深度定制另计：H5 特殊页面、历史系统迁移、复杂报表、专属集成。

## 成交前必须确认

- 老板认可“小优是数字员工，不是全自动系统”。
- 老板能接受先小范围试点。
- 老板愿意提供机构事实资料。
- 老板接受高风险动作必须确认。
- 老板接受试点期间以价值证据复盘，而不是只看功能清单。
