# 小优真实数字员工闭环 V1

日期：2026-08-13

## 一、项目目标

小优不是等待老板逐条下命令的聊天助手，而是托管机构数字员工。它围绕老板确认的经营目标持续恢复工作：

`经营目标 -> 调查事实 -> 制定阶段 -> 主动找人 -> 分配低风险任务 -> 收取回复 -> 验证结果 -> 调整计划 -> 完成目标`

模型负责理解事实、判断优先级、选择对象、决定时机、组织表达和调整行动。系统只负责身份、正式授权、在职状态、学生责任关系、频率、幂等、审计、原子写入、写后反查、发送回执和外发边界。

## 二、当前工作机制

### 1. 正式主动授权

- 老板授权保存到 `proactive_authorizations.jsonl`，可调整、撤销、设置人员、角色、行动类型、目标范围、每日频率和有效期。
- 实际权限由机构默认边界、老板正式授权、灰度白名单、人员在职状态和当前时间窗共同决定。
- 撤销授权会停止尚未发送的消息；已经进入发送中的消息标记为结果未知，不假装已经停止或送达。
- 当前生产灰度只允许机构负责人 `owner_test` 和示例老师测试号 `teacher_test`；家长始终禁止主动触达。

### 2. 候选到真实发送

- 模型决定现在需要问人时，先形成有原因、对象、具体问题和证据要求的主动联系候选。
- 候选重新通过授权、角色、在职状态、时间窗、频率和幂等检查后进入 outbox。
- 发送前再次复核授权与在职状态，避免授权撤销或员工离职后仍发出旧消息。
- 状态区分 `candidate / authorized / queued / sending / sent / replied_partial / replied_sufficient / resolved`，异常区分 `retry_pending / failed / result_unknown / expired / superseded / escalated`。
- 只有 `sent` 回执后才能说已经发送；`queued` 只能说已安排发送。

### 3. 持久目标行动

- 老板确认目标后，目标不仅保存方案，还会建立 `goal_actions.jsonl` 行动账本。
- 每个行动记录目标、阶段、对象、事实归属人、计划时间、截止时间、证据要求、重试次数和升级路径。
- 每次白天自然唤醒恢复到期行动，模型选择执行、等待、调整、停止或升级；夜间只复盘，不外发。
- 没有可直接派发的行动时，至少建立一项事实基线核查，避免目标只剩静态文字。

### 4. 目标内低风险任务

- 只有老板已确认的目标才能生成自主子任务。
- 系统必须从学生档案和责任解析中证明目标老师确实负责该学生；责任不清或对象不一致时，先找店长或老板补事实，不能派错人。
- 每位老师每天最多一个新目标子任务，全机构每天最多三个；相同目标、学生和动作不得重复。
- 小优可以安排老师完成家校沟通任务，但小优本身不联系家长。
- 工资、绩效、处罚、制度、权限、删除和安全最终闭环不能自主执行。

### 5. 回复与结果验证

- 老师回复时会带入当前任务、主动线程和目标行动；唯一锚点自动衔接，多线程不明确时只问一个关键问题。
- 事实不完整进入 `replied_partial`，只追问缺少的一项；完整回复进入 `replied_sufficient`，仍不等于目标完成。
- 主模型再次核验证据后，行动依次记录 `verified` 和 `resolved`，并把学生事实写入目标进度。
- 老师连续两次低频追问仍无回复时，转成店长核实行动；只有目标阻塞、高风险或经营取舍才找老板。

### 6. 取消与恢复

- 目标撤销、主动授权撤销、任务取消、员工离职或责任关系变化后，相关未发送消息和开放行动停止，历史只追加状态，不物理删除。
- 自主唤醒每次从真实账本恢复，不依赖长会话记忆，也不把旧候选说成当前工作。
- 老板健康查询可看到授权、目标阶段、计划/执行/等待/验证数量、发送与回复状态、重复失败和未验证承诺。

## 三、当前灰度

1. 第一批：机构负责人与示例老师测试号，验证至少三条“主动发送 -> 回复 -> 证据更新”链路并观察 48 小时。
2. 第二批：加入店长 `CuiXiaoXia`，完成两条运营事实闭环并再观察 48 小时。
3. 第三批：只开放企业微信中在职且批准的老师，首周每人每天最多一条。

任一阶段出现错人、重复发送、跨人记忆、未经授权任务、家长外发、虚假成功或无法取消，立即退回上一阶段。

## 四、老板如何使用

- 给出经营目标并明确确认，例如“8 月完成所有正式托管学生的一次有效家校沟通”。
- 小优会先核对学生范围和责任关系，再保存行动并在授权范围内推进。
- 老板不需要逐步告诉小优每一步做什么；只在制度、敏感人事、高风险、安全或经营取舍时拍板。
- 可随时问“这个目标现在推进到哪一步、在等谁、证据是什么”，也可撤销目标或主动授权。

## 五、不可变边界

- 不直接联系家长。
- 不自动改工资、绩效、制度、权限或删除业务数据。
- 不把候选说成已执行，不把入队说成已送达，不把计划说成结果。
- 不让固定 Router 替模型做业务判断。
- 不复制示例机构真实数据到其他租户。
