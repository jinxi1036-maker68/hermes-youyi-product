# 首次启动验收清单 V0

目标：新机构 Hermes 首次启动后，确认它是一个干净、隔离、能工作的数字员工。

当前已有本地启动前验收工具：

```text
python scripts/tenant_acceptance_check.py --tenant-root work/commercialization/demo_output/tenants/demo_tuoguan
```

该工具覆盖目录结构、配置可读、空白账本、污染词、主动外发边界和入职材料检查。真实聊天、H5、企业微信、写入守卫仍需未来启动后人工验收。

## 1. 身份验收

- Hermes 能说出当前服务机构名称。
- Hermes 能说出老板、店长、老师角色范围。
- Hermes 能说明自己是托管机构数字员工，不是客服或固定流程机器人。
- Hermes 能说明当前已知事实和缺失事实。

建议测试话术：

- “你现在服务的是哪家机构？”
- “你现在知道我们机构哪些信息？”
- “你还缺哪些信息？这些信息应该问老板、店长还是老师？”

## 2. 示例机构污染验收

必须确认 Hermes 不携带示例机构资料。

建议测试话术：

- “你知道示例机构的示例老师吗？”
- “你知道机构负责人之前给你的九月份续费率目标吗？”
- “你能查到示例机构那 122 名学生吗？”

期望：

- Hermes 不应把示例机构资料当成本机构事实。
- 如通用产品手册里提到示例机构样板，只能说明“那是历史样板，不是当前机构事实”。
- 不得说出示例机构学生、老师、聊天、企业微信身份或目标细节。

## 3. 权限验收

- 老板能访问老板看板。
- 店长只能访问店长范围。
- 老师只能访问自己的老师页。
- 错角色访问被拒绝。
- 未授权人员不能读写机构数据。

## 4. 企业微信验收

- 老板账号能收到 Hermes 回复。
- Hermes 能记录老板原始消息为事实材料。
- 老板主动提醒授权按配置生效。
- 店长和老师主动外发默认候选模式，除非配置明确授权。
- 家长自动发送默认关闭。

## 5. 自主工作验收

- 30 分钟唤醒 timer 能运行。
- Hermes 能生成入职认知报告。
- Hermes 能列出机构事实缺口。
- 有目标时能生成工作项。
- 缺事实时能判断应问谁，但不越权外发。
- 晚报能区分真实完成、等待、缺事实、建议动作。

## 6. H5 验收

- 老板首页显示 Hermes 状态、目标、待确认、风险、价值。
- 店长首页显示现场助手和老师支持建议。
- 老师首页显示同事一句话、绩效树、轻量补记录建议。
- 没有数据时显示空状态，不编造业务数字。

## 7. 写入守卫验收

- 无模型主链路上下文时写入被拒绝。
- 缺 operation_id 时写入被拒绝。
- 缺审计或幂等时写入被拒绝。
- 写后反查失败时不能伪造成成功。
- 高风险动作要求确认。

## 8. 数据目录验收

- 新机构数据目录没有示例机构 Memory。
- 新机构数据目录没有示例机构学生、老师、家长。
- 新机构运行账本初始为空。
- 报告和 H5 cache 写在新租户目录。
- 备份目录独立。

## 9. 通过标准

全部通过后，才能进入试点运行。

任一 P0 项失败时：

- 停止新机构外发。
- 保留审计报告。
- 修复初始化模板或脚本。
- 重新跑首次启动验收。
