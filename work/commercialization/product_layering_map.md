# Hermes 产品分层图 V1

目标：把 Hermes 拆成未来可交付产品的不同层，明确什么能复用、什么要新机构填写、什么必须隔离、什么禁止复制。

## 1. 产品通用层

这些能力可复制给所有托管机构，是 Hermes 产品母版的一部分。

| 内容 | 是否可复制 | 是否需新机构填写 | 是否必须隔离 | 说明 |
| --- | --- | --- | --- | --- |
| 数字员工身份 | 是 | 否 | 否 | Hermes 是托管机构数字员工，不是 Router 或表单机器人。 |
| 模型主导原则 | 是 | 否 | 否 | 模型自己理解、判断、追问、查询、写入、等待或停止。 |
| 权限与写入守卫 | 是 | 是 | 是 | 产品规则通用，但每家机构的人员、角色、权限不同。 |
| 审计、幂等、写后反查 | 是 | 否 | 是 | 能力通用，账本数据按机构隔离。 |
| 早报、晚报、自主唤醒 | 是 | 是 | 是 | 节奏通用，时间窗口和外发授权按机构配置。 |
| H5 角色结构 | 是 | 是 | 是 | 老板、店长、老师三类角色通用，展示数据隔离。 |
| 主动存在感与关系经营 | 是 | 是 | 是 | 能力通用，主动外发授权和频率按机构配置。 |
| 多 Agent 影子分析 | 是 | 是 | 是 | 参谋能力通用，输入和输出必须按机构隔离。 |
| 存储治理与资源巡检 | 是 | 否 | 是 | 工具通用，报告和数据按机构隔离。 |

## 2. 托管行业通用层

这些是托管行业业务能力，适合沉淀成行业手册和标准功能。

| 内容 | 是否可复制 | 是否需新机构填写 | 是否必须隔离 | 说明 |
| --- | --- | --- | --- | --- |
| 续费推进 | 是 | 是 | 是 | 方法通用，学生名单、风险分组、责任老师属于机构专属。 |
| 招生与转化 | 是 | 是 | 是 | 线索、试听、话术、跟进状态按机构配置。 |
| 学生记录与画像候选 | 是 | 是 | 是 | 画像方法通用，孩子事实绝不跨机构。 |
| 家校沟通支持 | 是 | 是 | 是 | 制度通用，家长消息默认不自动发送。 |
| 老师减负与素材整理 | 是 | 是 | 是 | 方式通用，老师聊天和记录归属本机构。 |
| 店长现场助手 | 是 | 是 | 是 | 现场优先级方法通用，数据属于机构。 |
| 绩效候选 | 是 | 是 | 是 | 只做证据候选和试算，最终规则由机构确认。 |
| 经营机会发现 | 是 | 是 | 是 | 从记录中发现课程/项目机会，不能把其他机构经验当本机构事实。 |

## 3. 机构专属层

这些必须由每家机构单独填写或运行后生成，不能从优益复制。

| 内容 | 是否可复制 | 是否需新机构填写 | 是否必须隔离 | 说明 |
| --- | --- | --- | --- | --- |
| 机构名称、校区、品牌 | 否 | 是 | 是 | 新机构基础身份。 |
| 老板、店长、老师账号 | 否 | 是 | 是 | 影响权限、外发、H5 登录和主动提醒。 |
| 学生名单和服务关系 | 否 | 是 | 是 | 包括午托、晚托、全托、班级、主责老师。 |
| 企业微信配置 | 否 | 是 | 是 | CorpID、AgentID、Secret、回调密钥等不能共享。 |
| 工资与绩效制度 | 否 | 是 | 是 | 机构确认前不能自动算最终工资。 |
| 作息时间和忙碌时段 | 否 | 是 | 是 | 决定主动联系窗口和打扰边界。 |
| 家校沟通制度 | 否 | 是 | 是 | 例如月度沟通、每周记录要求。 |
| 当前目标和经营重点 | 否 | 是 | 是 | 老板输入或确认后才进入工作项。 |
| Memory 与机构事实 | 否 | 运行生成 | 是 | 只能保存在本机构。 |
| 自主工作账本 | 否 | 运行生成 | 是 | work item、attention、日报、候选、价值账本。 |

## 4. 优益专属层

这些只属于优益样板，不能直接复制给其他客户。

| 内容 | 是否可复制 | 是否需新机构填写 | 是否必须隔离 | 说明 |
| --- | --- | --- | --- | --- |
| 优益机构名称和手册事实 | 否 | 否 | 是 | 只能作为样板经验参考。 |
| 金总、李老师等具体人员 | 否 | 否 | 是 | 真实身份和权限不能进入新机构。 |
| 122 名历史学生口径 | 否 | 否 | 是 | 只能留在优益数据内。 |
| 2026 年 9 月续费目标 | 否 | 否 | 是 | 优益当前目标，不属于产品母版。 |
| 优益企业微信映射 | 否 | 否 | 是 | 不能复制给其他机构。 |
| 优益运行日报和唤醒报告 | 否 | 否 | 是 | 属于优益运营历史。 |
| 优益调试故障和修复绕路 | 否 | 否 | 是 | 可转成产品测试，不进客户记忆。 |

## 5. 实验能力层

这些能力可以继续在优益灰度，但正式商业化前必须标明状态。

| 内容 | 当前状态 | 商业化处理 |
| --- | --- | --- |
| 老师主动关心外发 | 候选模式 | 新客户默认关闭，授权后单人灰度。 |
| 店长主动提醒外发 | 候选模式 | 新客户默认关闭，授权后低频灰度。 |
| 老板主动存在感 | 已开放老板侧 | 新客户需在开通时确认时间和频率。 |
| 多 Agent 影子复核 | 灰度 | 只读参谋，不能直接管理机构。 |
| 公网行业学习 | 灰度 | 必须带来源，审核前不进入正式经验。 |
| 绩效证据候选 | 灰度 | 只做候选和试算，不做最终工资结论。 |

## 6. 禁止复制层

这些材料未来交付新机构时必须排除。

- 聊天记录、企业微信原始消息、老板私密对话。
- 学生、家长、老师真实个人资料。
- 企业微信密钥、回调 token、EncodingAESKey、应用 Secret。
- 优益 Memory、优益目标账本、优益自主工作账本。
- 调试日志、测试失败、绕路经验、临时脚本输出。
- 任何包含旧机构身份、名单、工资、绩效、家校沟通内容的文件。
