# Hermes/小优维护包 V0

目标：把当前优益样板生产和未来单机构试点的维护动作标准化，避免靠临时经验操作。

## 文件说明

- `production_maintenance_runbook.md`：日常巡检、日志核对、timer 核对和异常分级。
- `minimal_upgrade_rollback_flow.md`：最小同步、备份、重启、验证和回滚流程。

## 维护原则

- 先只读观察，再判断是否需要改动。
- 任何生产写入前必须有备份和明确回滚点。
- 不清理未知历史模块。
- 不手动触发真实外发。
- 不迁移业务数据，除非有单独迁移计划和验收。
- 小优能力问题先看模型材料和边界，不退回固定 Router。
