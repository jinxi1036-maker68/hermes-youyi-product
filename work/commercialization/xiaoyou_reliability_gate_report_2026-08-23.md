## 发现并修复的问题

1. 影子环境原来使用旧 Agnes 测试 Key，与生产 Key 不一致。现在影子配置只抽取生产模型路由，并在测试前做密钥指纹等值核对；不复制企业微信和业务凭据。
2. 生产 `fallback_providers` 是 JSON 字符串，Hermes 官方 fallback 链不会按规范加载。调优脚本现在安全迁移为 YAML 列表，并保留密钥、不在报告中输出密钥。
3. 调优脚本原子替换配置后可能把权限从 `600` 放宽为 `644`。现在保留并反查原权限。
4. Hermes v0.20 会在传输失败后重试一次再切备用。单次模型超时收紧为 12 秒，完整主主备路径受 35 秒网关上限约束。
5. 一次性低风险测试任务可能误绕到目标工作区。任务契约已明确直接使用 `create_task`。
6. 物流快递等“托管”同词污染检查可能查询正确但结论含糊。学习契约已要求明确隔离且不生成教培趋势。
7. 领域工具嵌套参数曾被影子验收器误判。验收器现按真实 facade 参数结构检查。
