# XiaoYou skill availability

The candidate carries two local XiaoYou skills:

1. `xiaoyou-core-contract`
2. `xiaoyou-observation-evidence`

They are the complete set of local XiaoYou skills confirmed enabled in the
observed production model environment. Hermes built-in skills are supplied by
the Hermes runtime and are not duplicated here. A name mentioned by an old
bundle, old document, or planned design is not an installed skill.

`runtime/skill-bundles/xiaoyou-core.yaml` is the source-of-truth local bundle
for this candidate and intentionally includes only the two entries above.
